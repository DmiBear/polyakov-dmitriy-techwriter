# Группировка профилей

Группировка профилей в сервисе «Поиск по людям» позволяет объединить ваши профили из разных социальных сетей в один результат поиска.

Профили будут сгруппированы автоматически при выполнении одного из следующих условий:
* Два профиля содержат **взаимные ссылки** друг на друга.
* Один профиль содержит **подтверждённую ссылку** на другой. Подтверждённой считается ссылка, добавленная через официальный интерфейс социальной сети, где может потребоваться вход в аккаунт.

## Процесс группировки

Общий процесс настройки группировки состоит из следующих этапов:
1. Авторизация в сервисе Яндекса.
2. Добавление и подтверждение профилей социальных сетей.
3. Отправка запроса и завершение процесса.

## Авторизация в сервисе

### При наличии аккаунта Яндекс

Чтобы начать работу, необходимо авторизоваться в сервисе управления социальными связями Яндекса.

1. Перейдите на страницу [social.yandex.ru](https://social.yandex.ru).
2. Выберите социальную сеть, с которой будете выполнять группировку профителей. 
3. Выполните вход с помощью вашего аккаунта Яндекса или одной из предложенных социальных сетей (например, ВКонтакте).

### При отсутствии аккаунта Яндекс

1. Перейдите на страницу [social.yandex.ru](https://social.yandex.ru).
2. Выберите раздел «Еще».
3. Нажмите на кнопку «восстановить доступ».
4. Добавьте социальную сеть.

## Добавление ссылки на профиль в других социальных сетях

1. В интерфейсе сервиса выберите нужную социальную сеть.
2. Предоставьте запрашиваемые разрешения для доступа.
3. Нажмите кнопку **«Привязать аккаунт»**
