# Поляков Дмитрий — технический писатель

Создаю пользовательскую и эксплуатационную документацию для информационных систем и веб-сервисов: от анализа исходных материалов до готового руководства с проверенными сценариями и иллюстрациями.

## О портфолио

В репозитории собраны законченные примеры пользовательской и эксплуатационной документации. Материалы представлены в формате Markdown, а ключевое руководство дополнительно оформлено как отдельный docs-as-code-проект на MkDocs.

Работы показывают, как я структурирую большой объём информации, описываю действия пользователя, связываю текст с интерфейсом и готовлю документацию к публикации.

Иллюстрации и примеры данных обезличены. Внутренние документы, сведения о заказчиках и материалы, которые ещё проходят редактуру, не публикуются.

## Ключевая работа

### Платформа ГИСОГД

[Руководство пользователя платформы ГИСОГД](https://dmibear.github.io/gisogd-user-guide/) — отдельный сайт документации, подготовленный на MkDocs и опубликованный с помощью GitHub Pages.

Руководство охватывает подготовку к работе, навигацию, таблицы и записи, карту, обработку заявлений, документы и реестры системы. Материал разделён на тематические страницы, снабжён поиском и обезличенными иллюстрациями интерфейса.

- [Исходники MkDocs-проекта](https://github.com/DmiBear/gisogd-user-guide)
- [Версия руководства в одном Markdown-файле](<Руководство_пользователя_платформа_ГИСОГД.md>)

Проект демонстрирует полный цикл docs-as-code: организацию структуры документации, работу с Markdown и изображениями, управление версиями в Git и автоматическую публикацию сайта через GitHub Actions.
