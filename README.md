# Поляков Дмитрий — технический писатель

Создаю пользовательскую и эксплуатационную документацию для информационных систем и веб-сервисов: от анализа исходных материалов до готового руководства с проверенными сценариями и иллюстрациями.

## О портфолио

В репозитории собраны законченные примеры документации в формате Markdown. Они показывают, как я структурирую большой объём информации, описываю действия пользователя, связываю текст с интерфейсом и оформляю материалы для публикации в Git.

Иллюстрации и примеры данных обезличены. Внутренние документы, сведения о заказчиках и материалы, которые ещё проходят редактуру, не публикуются.
